# Rigidbody 2D
Learn how Rigidbody 2D works.Read time 1 minuteLast updated 23 days agoRigidbodies enable physics-based behavior, such as reactions to gravity, mass, drag, and momentum. A Rigidbody 2D is a 2D component you can use to enable an object to act under the control of physics.
