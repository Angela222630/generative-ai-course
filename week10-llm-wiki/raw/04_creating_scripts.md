# Creating scripts
Create scripts to add programmable functionality to your application.Read time 1 minuteLast updated 2 months agoScripts allow you to customize and extend the capabilities of your applicaton with C# code. With scripts that derive from Unity's built-in [MonoBehaviour](/en-us/engine/6000.0/manual/scripting/get-started/fundamental-unity-types/class-mono-behaviour) class you can create your own custom Components to control the behavior of GameObjects. With scripts that derive from [ScriptableObject](/en-us/engine/6000.0/manual/scripting/get-started/fundamental-unity-types/class-scriptable-object) you can store large amounts of data efficiently in your application. Alternatively, you can start with an empty C# script to develop your own non-Unity classes.
Unlike most other assets, scripts are usually created within Unity directly. To create a new script:

* From the main menu: go to **Assets > Create > Scripting** and select the type of script you want to create.

Or:

* From the Create menu (plus sign) in the [Project window toolbar](/en-us/engine/6000.0/manual/unity-editor/editor-windows-views-reference/project-view): go to **Scripting** and select the type of script you want to create.

This creates a new script in whichever folder you have selected in the Project panel. It also selects the script's file name for editing, prompting you to change the name. For things you should take into account when naming your scripts, refer to [Naming considerations for scripts](/en-us/engine/6000.0/manual/scripting/get-started/naming-scripts).
