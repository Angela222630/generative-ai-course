Chapter 02 • Core Concept

萬物的容器：什麼是 GameObject？

Unity 編輯器中最核心的概念——一切實體的起點

📦 GameObject 的本質：空容器

在 Unity 中，遊戲世界中的一切實體都是 GameObject，從主角小狗、雪地、背景樹木，到看不見的燈光（Light）與攝影機（Camera）。

⚠️ 重要特性：GameObject 本身無法單獨發揮任何具體功能！它只是一個「空的容器（Container）」。

想要讓它具備外觀或功能，必須在它上面「掛載」對應的配件，這些配件就稱為 Component（組件）。

🐕 雪地場景中的 GameObject 角色

  • Dog GameObject：掛上貼圖組件變成狗狗。
  • Snow Ground：掛上瓦片組件變成雪地。
  • Main Camera：預設的攝影機 GameObject，負責拍攝畫面。
  • Directional Light：照亮雪地的環境光來源。

📌 概念總結：Scene（場景）是容納這群 GameObject 的世界容器，而 GameObject 則是承載具體功能的個體容器。

Chapter 03 • Components

賦予物件靈魂：Component 與唯一必備的 Transform

認識組件組合模式（Composition）與空間三要素

🧩 Component（組件）的職責

組件是真正實作遊戲功能與外觀的核心單位：

  • 照亮場景：GameObject 掛載 Light 組件。
  • 繪製方塊：組合 Mesh Filter、Mesh Renderer。
  • 實體碰撞：掛載 Box Collider 組件。

在 Unity 檢查器（Inspector）中，你可以自由添加或移除各種功能組件。

⭐ 唯一不可刪除的核心組件：Transform

任何 GameObject 在被建立的瞬間，必定會自動掛載一個 Transform 組件，且絕對無法被移除！

Transform 負責記錄該物件在空間中的三大核心數值：

  1. Position（位置）：世界座標 (X, Y, Z)。
  2. Rotation（旋轉）：旋轉角度。
  3. Scale（縮放）：長寬高縮放比例。

Chapter 04 • 2D Rendering

看見狗狗：Sprite Renderer 組件與外觀控制

如何讓 2D 精靈貼圖出現在遊戲畫面上？

🖼️ Sprite Renderer 的核心角色

在 2D 遊戲中，如果想讓 GameObject 顯示出 2D 圖片（Sprite），就必須在該物件掛載 Sprite Renderer 組件。

它會讀取物件上的 Transform 座標與縮放，並將圖片精準繪製到螢幕畫面上。

🎨 Material 材質：Unity 6 預設使用 Sprite-Lit-Default 材質，能自動適應 2D 光照。

⚙️ 初學者 Inspector 常用屬性

  • Sprite：指定要繪製的圖片（將雪地狗狗圖片拖曳進來）。
  • Color：疊加調色濾鏡（預設純白代表原圖無染色）。
  • Flip（翻轉）：沿 X 軸或 Y 軸鏡射貼圖。
    關鍵特性 勾選 Flip 只翻轉外觀貼圖，完全不改變 GameObject 本身的 Transform 座標（非常適合狗狗轉身向左/向右）。
  • Draw Mode：Simple（均勻縮放）、Sliced（九宮格拉伸）、Tiled（平鋪）。

Chapter 05 • Layer Sorting

前後分明：Sorting Layer 與 Order in Layer

徹底解決 2D 平面物體被地圖穿透或遮擋的問題

🥪 誰站在前面？2D 遮擋問題

2D 遊戲所有物體都在同一平面，如果狗狗走到雪地草叢邊，畫面會先畫誰？

Unity 透過兩層機制精準控制前後順序：

  1. Sorting Layer（排序圖層）：大分類（如 Background 背景層、Characters 角色層、Foreground 前景層）。依照清單順序由底至頂渲染。
  2. Order in Layer（內部順序）：同一圖層內部的整數排序數值。

📐 核心渲染規則（考試必考！）

Unity 永遠先渲染數值較小的物件，再渲染數值較大的物件。

因此，在同一 Sorting Layer 且物件重疊時：

數值越大（Higher values） ➔ 顯示在最前方遮擋前物！

💡 範例：雪地地面設為 Order in Layer = 0，狗狗設為 Order in Layer = 2，則狗狗會站在雪地地面上方！

Chapter 06 • Level Design

像畫畫一樣鋪設關卡：Tilemap 與 Tile Palette

利用瓦片地圖系統快速建立 2D 雪地世界與地形障礙

🎨 什麼是 Tilemap？

Tilemap 讓開發者透過「將瓦片繪製（Painting Tiles）到場景網格上」的方式，直觀快速拼湊出廣闊的地形（如雪地平原、冰湖與岩石障礙）。

瓦片作畫兩大步驟：

  1. 建立 Tile Palette（瓦片調色盤）：放作畫用瓦片資產（Tile assets，官方定義為矩形、等角或六邊形的 Sprite）。
  2. 建立 Tilemap 網格畫布：選取調色盤上的瓦片，用筆刷工具直接在場景中刷出地面。

📐 三大瓦片網格佈局（Layout Types）

  • Rectangular（矩形 / 正方形）：
    系統預設 最常見的四邊形網格，適合橫向捲軸與俯視角 2D 關卡。
  • Hexagonal（六邊形）：
    蜂巢狀排列（尖角朝上或平邊朝上），常見於回合制戰棋與策略遊戲。
  • Isometric（等角投影）：
    斜角 2D 網格，能在 2D 平面營造出 2.5D 立體空間高度與深度錯覺。

Chapter 07 • Scripting

撰寫程式行為：C# 腳本與 MonoBehaviour

認識腳本在 Unity 中的定位：自訂組件（Custom Components）

🧠 腳本即自訂組件（核心心智模型）

有了狗狗外觀和雪地地圖，如果想讓狗狗具備智慧或自訂行為，就需要寫 C# 程式碼。

繼承自 Unity 內建 MonoBehaviour 類別的腳本，本質上就是開發者親手打造的「自訂組件（Custom Components）」！

只要將寫好的腳本掛載至狗狗 GameObject 上，它就能像其他內建組件一樣控制物件的具體行為。

🛠️ 如何在 Unity 編輯器中建立腳本？

腳本通常直接在 Unity 內部建立，有兩種管道：

  • 主選單：點擊 Assets > Create > Scripting 選擇腳本類型。
  • 專案視窗工具列：點擊加號按鈕 + > Scripting。
⚠️ 命名小叮嚀：建立時 Unity 會立即提示重新命名，務必讓腳本檔案名稱與程式內的類別名稱完全保持一致！

Chapter 09 • 2D Physics

重力與物理規律：認識 Rigidbody 2D 組件

讓雪地狗狗受 2D 物理引擎驅動與重力控制

🪂 Rigidbody 2D 的本質

Rigidbody 2D 是一個 2D 核心物理組件。只要掛載它，就能讓 GameObject 在 2D 物理引擎的控制下行動（act under the control of physics）。

掛載後，物件會自然具備四大基本物理反應：

  • Gravity（重力）：受重力牽引自然向下墜落。
  • Mass（質量）：物體本身的質量數值。
  • Drag（阻力）：運動時受到的空氣阻力。
  • Momentum（動量）：物體具備的慣性衝量。

⚙️ 核心屬性與模擬控制

1. Body Type（剛體類型）

定義剛體在物理世界的行為模式（例如受重力自由下墜的動態剛體，或是固定不動的靜態地面障礙物）。

2. Simulated 屬性（物理開關）

控制該剛體及其關聯碰撞體是否參與 2D 物理模擬計算的總開關（Start / Stop）。關閉時物體將被物理引擎暫停計算。

Chapter 10 • Testing & Verification

測試你的雪地世界：The Toolbar 與 Play Mode

使用編輯器頂部工具列進行即時運行測試與單幀除錯

🎮 Play Mode Controls（核心三按鈕）

位於 Unity 頂部固定工具列（Toolbar）正中央，用來控制在 Game view（遊戲視窗） 中的運行狀態：

▶ Play（播放）：切換編輯器進入運行模式，即時測試遊戲效果；再按一次則退出。
❚❚ Pause（暫停）：凍結當前遊戲運行畫面，方便從容檢查物件數值。
⏯ Step（步進）：在暫停時點擊，使遊戲向前推進恰好一個影格（move forward by one frame），進行極為精密的逐幀除錯！
Q1. 在 Unity 中，當你建立任何一個新的 GameObject 時，哪一個組件必定自動存在且無法被刪除？
💡 解析：依據官方文件，任何 GameObject 建立時必定自動掛載 Transform 組件（負責記錄 Position, Rotation, Scale），且無法被刪除。（來源：wiki/01_basics.md）
Q2. 在同一 Sorting Layer、兩個 Sprite 重疊時，如果雪地地面的 Order in Layer 設定為 0，而狗狗的 Order in Layer 設定為 2，兩者的前後顯示關係為何？
💡 解析：在同一圖層重疊時，Unity 渲染規則是「先渲染數值較小者，再渲染數值較大者」。因此數值越大（Higher values）會顯示在最前方遮擋數值較小者。（來源：wiki/02_sprites.md）
Q3. 在 Unity 頂部工具列中，當遊戲處於暫停（Pause）狀態時，點擊「Step」按鈕具體有什麼效果？
💡 解析：Step 按鈕在暫停時可使遊戲「向前推進恰好一個影格（move forward by one frame）」，是極為便利的單幀除錯工具。（來源：wiki/06_playmode.md）
